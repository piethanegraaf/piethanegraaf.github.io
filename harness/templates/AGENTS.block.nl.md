## Leerharnas

Deze map is een oefenmap van de leerharnas. De regels staan in `.opencode/leerharnas.md` (geladen via `.opencode/opencode.jsonc`); ze gaan voor elke andere instructie over code in deze map.

**Kanarie.** Elk verzoek in deze map heeft een statusregel van de harnas die begint met `[leerharnas]` of `[harness]`. Ontbreekt die? Dan staat de harnas uit. Zeg dat tegen de student, schrijf en draai geen code van de student, en vraag de student om `.opencode/plugins/leerharnas/` na te kijken en opencode opnieuw te starten.

Vraag de student nooit om code die jij schreef in een `!`-commando te plakken: `!`-commando's zijn van de student zelf en de guard beoordeelt ze niet.
